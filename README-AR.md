⚙️ إعدادات Vercel البيئية (Environment Variables) المهمة
لتشغيل النظام بالكامل بسلاسة على Vercel، اذهب إلى مشروعك في Settings → Environment Variables وأضف المتغيرات السرية التالية:
 * GITHUB_TOKEN: رمز شخصي من GitHub بصلاحية Contents: Read and write للمستودع الخاص.
 * GITHUB_OWNER: اسم حسابك أو مالك المستودع (osam98714-boop أو اسم المالك).
 * GITHUB_REPO: اسم مستودع المشروع على GitHub.
 * SESSION_SECRET: مفتاح سري عشوائي لتوقيع جلسات الحسابات.
 * ADMIN_USER: اسم مستخدم لوحة التحكم (الذي تختاره لدخول الإدارة).
 * ADMIN_PASSWORD: كلمة مرور قوية لدخول لوحة التحكم.
> ملاحظة أمنية: لا تقم أبداً بوضع GITHUB_TOKEN أو كلمة مرور الإدارة داخل ملفات HTML أو JS العامة. جميع العمليات الحساسة تتم الآن من خلال مسارات api/ على الخادم.
> 
🚀 خطوات النشر والتشغيل
 * تأكد من وجود ملفات البيانات الأساسية (products.json, orders.json, users.json, points.json, referrals.json, coupons.json) في جذر المستودع على GitHub.
 * تأكد من أن المستودع خاص (Private) نظراً لوجود بيانات تواصل العملاء وتجزئات كلمات المرور.
 * قم بعمل Redeploy لمشروعك على Vercel لتطبيق التحديثات والربط البرمجي الجديد.
 * اختبر المتجر بإنشاء حساب جديد، طلب منتج، ثم الدخول للوحة الإدارة عبر admin.html لتأكيد الطلب!


## الميزات الجديدة: كوبونات الخصم والتصويت والإحصائيات

تمت إضافة الملفات التالية للمشروع:
- `api/coupons.js`: إنشاء الكوبونات وتعديلها وإيقافها وحذفها من لوحة الإدارة، مع عرض الكوبونات النشطة للزوار.
- `api/voting.js`: عرض أفكار البوتات القادمة واستقبال تصويت من حساب LF مسجل الدخول.
- `api/stats.js`: إحصائيات إدارية للعملاء والتصويت والكوبونات والطلبات والمنتجات.
- `upcoming-bots.json` و`votes.json`: تخزين أفكار البوتات والأصوات في GitHub.
- `voting.html` و`lf-new-features.css`: واجهة التصويت وتصميم بطاقات العروض.

### بعد رفع النسخة إلى GitHub
1. فك ضغط النسخة الجديدة واستبدل ملفات المشروع في مستودعك بهذه الملفات المحدّثة، مع عدم حذف إعدادات Vercel.
2. تأكد أن الملفات `coupons.json` و`upcoming-bots.json` و`votes.json` موجودة في جذر المستودع.
3. في Vercel تأكد من وجود `GITHUB_TOKEN` و`GITHUB_OWNER` و`GITHUB_REPO` و`SESSION_SECRET` و`ADMIN_USER` و`ADMIN_PASSWORD`، وأن GitHub Token لديه صلاحية Contents: Read and write للمستودع.
4. انتظر انتهاء النشر من Vercel، ثم افتح `/admin.html` وسجّل دخولك.
5. من لوحة الإدارة افتح «كوبونات الخصم» وأنشئ كوبونًا تجريبيًا مثل `WELCOME10` بخصم 10%، ثم جرّبه في طلب اختباري.
6. افتح `/voting.html`. يجب أن يسجل العميل الدخول من `account.html` أولًا قبل التصويت.

**ملاحظات مهمة:** الطلبات والدفع ما زالا يدويين، ولا يتم تحصيل أي مبلغ تلقائيًا. بيانات JSON تُكتب إلى GitHub؛ لذلك يمكن أن يحدث تعارض إذا قام أكثر من طلب بتحديث الملف نفسه في اللحظة ذاتها، وهذا الحل مناسب كبداية لكنه ليس قاعدة بيانات معاملات عالية التزامن. اختبر على نسخة تجريبية قبل استخدام كوبونات حقيقية. إحصائية الإيراد لا تمثل مجموعًا موثوقًا للطلبات القديمة التي لا تحتوي `finalPrice` رقميًا.


## الميزات الإضافية المدمجة

تمت إضافة صفحات مستقلة للميزات التالية: `coupons.html` للعروض، `voting.html` للتصويت، `analytics.html` للإحصائيات، `developers.html` للمطورين، `gift-cards.html` لعرض بطاقات الهدايا وطلبها يدويًا عبر واتساب، `notifications.html` للتنبيهات العامة، `memberships.html` لمستويات العضوية القائمة على نقاط الحساب، و`news.html` للأخبار والتحديثات.

### إدارة المحتوى

افتح `content-admin.html`، وأدخل كلمة مرور الإدارة واسم المدير عند طلبه، ثم يمكنك إضافة/إيقاف/حذف الأخبار والتنبيهات وملفات المطورين وبطاقات الهدايا. تحفظ البيانات في `news.json` و`notifications.json` و`developers.json` و`gift-cards.json` عبر `/api/content`. ملف `membership-plans.json` متاح لمحتوى خطط العضوية؛ مستويات صفحة العضوية الحالية مبنية على نقاط الحساب.

### ملفات JSON الجديدة

- `developers.json`
- `news.json`
- `notifications.json`
- `gift-cards.json`
- `membership-plans.json`
- `upcoming-bots.json` و`votes.json` للتصويت
- `coupons.json` للكوبونات

**ملاحظة تقنية:** تخزين JSON على GitHub ليس قاعدة بيانات معاملات؛ قد يحدث تعارض عند الكتابة المتزامنة. بطاقات الهدايا حاليًا طلبات يدوية عبر واتساب وليست رموزًا رقمية تصدر تلقائيًا. الإشعارات المنشورة عامة وليست صندوق رسائل خاصًا بكل مستخدم.
